# 🎙️ 双语有声绘本工坊

把孩子的科普书做成**中英双语有声书**：输入文字段落 → 本机合成真人级朗读 → 配背景音效 → 导出成**一个可以随便发的网页播放器**。

循环播放、睡眠定时、逐句跟读高亮 —— 爸妈不用陪着念到嗓子哑。

---

## 快速开始

```bash
cd ~/bilingual-audiobook
node tools/serve.mjs
```

浏览器会自动打开 `http://localhost:5180/`：

| 页面 | 用途 |
|---|---|
| `/`（index.html） | **创作台** —— 编辑段落、试听、一键生成 |
| `/library.html` | **绘本馆** —— 所有做好的书 |
| `/dist/<id>.html` | 某本书的播放器 |

> 第一次用先点右上角 **📚 载入示例**，可以看到《食物链小学堂》的完整样子。

**为什么需要本地服务？** 浏览器不能直接调用 macOS 的 `say` 和 `ffmpeg`，`serve.mjs` 就是替它跑这些命令的那双手。创作台的「⭐ 生成音频」按钮会调它。

也可以完全不用网页，直接命令行生成：

```bash
node tools/build.mjs stories/food-chain.json
```

## 做一本新书

在创作台里：改标题 → 逐段填中英文 → 调语速和停顿 → **▶ 全程试听**确认节奏 → **⭐ 生成音频**。

背景氛围只需要写在**换场景的那一段**，后面会自动沿用：

```jsonc
{ "section": "④ 树林里", "en": "Now, into the forest.", "zh": "现在，我们走进树林。", "ambience": "forest" }
```

段落可选字段：

| 字段 | 作用 |
|---|---|
| `section` | 小节标题，会显示在播放器顶部 |
| `ambience` | 换背景氛围；`null` = 此处静音 |
| `sting` | 一次性音效：`pop` `chime` `whoosh` `drip` `twinkle` `heartbeat` |
| `pauseAfter` | 这段之后多停几秒（不写就用全局的「段与段停顿」） |
| `gapWithin` | 这段里中英之间停几秒 |

### 可用的背景氛围

🌿 草甸微风 · 🌳 树林 · 🌊 海浪 · 💧 池塘 · 🌧️ 下雨 · 🪐 太空 · 🌙 夜晚

全部是 ffmpeg 现场合成的，**不依赖任何音频素材文件**，而且渲染时会自动校准响度 —— 所以换场景时音量不会忽大忽小。

## 产出物

```
audio/<id>/
  <id>.m4a          人声 + 音效
  <id>.amb.m4a      背景氛围（单独一条轨，播放器里可一键关掉）
  manifest.json     逐句时间轴：播放器靠它做跟读高亮
dist/
  <id>.html                 播放器（音频分离，适合放网站）
  <id>.standalone.html      ★ 单文件版，音频已内嵌 —— 直接 AirDrop 发给孩子/老人，离线可用
```

`<id>.standalone.html` 是这个工具的核心产出：**一个文件就是一本有声书**，双击就能放，不需要联网、不需要服务器、不怕链接失效。

## 播放器的功能

- 🔁 **无限循环** —— 播完自动从头开始，直到你叫停
- ⏰ **睡眠定时** —— 5/10/20/30 分钟后在 20 秒内缓缓淡出再暂停，孩子睡着了不会突然没声
- 🐢 **慢速 / ⚡ 变速** —— 0.7× 到 1.5×
- 🌊 **一键关背景音** —— 有些孩子嫌吵
- ☰ **全文对照** —— 点任意一句直接跳过去
- 中英逐句高亮 + 自动滚动，适合跟读
- 锁屏 / 耳机线控支持（Media Session）
- 深色模式（睡前不刺眼）
- 键盘：`空格` 播放暂停，`←/→` 快退快进 10 秒，`↑/↓` 上/下一句

在 iPad 上「添加到主屏幕」就变成一个全屏 App。

## 原理

```
story.json
   │
   ├─ say -v Samantha / Tingting ──▶ 每段 wav（自动响度归一化到 -16 LUFS）
   │
   ├─ 按时间轴插入静音（中英之间 / 段与段之间）
   │
   ├─ ffmpeg 合成氛围床（按实际时长生成，所以没有循环接缝的咔哒声）
   │     └─ 自动标定：每条氛围先量响度，再补增益到统一目标
   │
   ├─ 混入一次性音效（adelay 定位）
   │
   └─ 编码 AAC ──▶ m4a + manifest.json ──▶ 注入播放器模板
```

### 两个踩过的坑

1. **`say -r` 不是词/分。** 实测 `say -r 158` 实际约 186 词/分（英文系数 ≈1.18），中文约 272 字/分（系数 ≈1.64）。创作台的时长估算和试听语速都按实测系数换算，否则会偏 30% 以上。
2. **媒体文件必须支持 HTTP Range。** 本地服务早期没实现 Range，浏览器 seek 会被静默吞掉 → 进度条、跳句、双轨同步全部失效。`serve.mjs` 现在返回 206 并带 `Content-Range`。

## 想更好听？

系统自带嗓音里，这两个已经在用了：

- 英文 `Samantha`，中文 `Tingting`（婷婷）

想更自然的话，去 **系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音** 下载 **Premium/增强** 音质（如 Ava、Tom、Zoe、婷婷-增强），下载完在创作台的嗓音下拉框里直接就能选。

```bash
say -v '?'        # 看本机所有可用嗓音
node tools/catalog.mjs   # 重新导出列表给创作台
```

## 命令

| 命令 | 作用 |
|---|---|
| `node tools/serve.mjs` | 启动工坊（默认 5180 端口） |
| `node tools/build.mjs stories/<id>.json` | 生成一本 |
| `node tools/build.mjs ... --no-embed` | 跳过 base64 内嵌，迭代时快很多 |
| `node tools/catalog.mjs` | 重新导出嗓音 / 氛围 / 音效清单 |

依赖：macOS 自带 `say`；需要 `ffmpeg`（`brew install ffmpeg`）和 Node 18+。
